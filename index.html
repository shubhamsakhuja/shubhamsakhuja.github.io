RetailMind — Multi-Agent Retail Intelligence
Portfolio flagship. A seven-agent LangGraph system (Supervisor, Data, Anomaly, Forecast, Recommendation, Insight, Critic) that share state through a typed GraphState with message passing. Runs on Claude via AWS Bedrock, with DuckDB plus Parquet, PostgreSQL, and ChromaDB underneath. Features a real-time SSE streaming agent dashboard, a custom MCP server, and a LoRA fine-tuned evaluator published to Hugging Face. Synthetic dataset of 1,000 Australian stores, 30,000 SKUs, and 5.5M transactions over three years with local seasonality.
LangGraph AWS Bedrock Claude MCP Server LoRA Fine-tuning DuckDB Parquet PostgreSQL ChromaDB FastAPI React Apache Airflow Docker AWS EC2 + S3 + ECR GitHub Actions
🏥

RadiSearch — Production RAG
Production radiology report intelligence platform deployed at Benson Radiology. Clinical staff query 100,000+ reports in plain English through semantic search, LLM summarisation, and fuzzy clinical term resolution, with retrieval cut from hours to under 30 seconds. A 6-step LLM pipeline runs intent parsing, fuzzy resolution, DB search, analytics, context building, and AI response. Privacy-first design runs inside the hospital network with Azure AD SSO and SSE streaming.
Claude · AWS Bedrock ChromaDB FAISS Sentence Transformers FastAPI PostgreSQL Azure AD SSO AWS EC2
✈️
⧡
AeroAnalytics — NL-to-SQL Platform
Full-stack AI analytics app that turns plain-English questions into validated SQL, interactive charts, and executive insights. A 4-node LangGraph pipeline (Planner, SQL Generator, Insight Generator, Critic) runs on Claude Haiku 4.5 via AWS Bedrock with Azure OpenAI GPT-4o as fallback. Covers a 44,657-row airline dataset across 17 tables, plus CSV, Excel, JSON, PostgreSQL, MySQL, and BigQuery. Deployed to AWS with CI/CD via GitHub Actions.
LangGraph Claude Haiku 4.5 AWS Bedrock Azure OpenAI Flask Chart.js BigQuery GitHub Actions CI/CD
